# Stock Price Analysis with Pandas & YFinance

A Python project to download historical stock data[cite: 2], analyze time series trends, compute moving averages, and visualize financial metrics using Pandas and Matplotlib.

## Project Requirements
- Download historical stock data for at least two companies using the `yfinance` library[cite: 2].
- Set the date column as the DataFrame index[cite: 2].
- Plot closing prices over time using line charts[cite: 2].
- Resample data to weekly and monthly frequency using `.resample()`[cite: 2].
- Compute 20-day and 200-day moving averages with `.rolling()`[cite: 2].
- Compare trading volume between the two companies[cite: 2].
